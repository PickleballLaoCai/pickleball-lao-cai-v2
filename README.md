# Pickleball Lào Cai V2

Nền tảng V2 được xây tách biệt với FIX7 (V1 production).

## Nguyên tắc
- Không làm gián đoạn FIX7.
- Không xóa/đổi schema Supabase hiện tại.
- Chuyển từng module và kiểm thử trước khi đưa vào production.
- Mobile-first.
- Dùng lại dữ liệu Supabase hiện tại khi bắt đầu kết nối dữ liệu.

## Giai đoạn hiện tại
Khung Next.js ban đầu. Chưa ghi dữ liệu vào Supabase production.
